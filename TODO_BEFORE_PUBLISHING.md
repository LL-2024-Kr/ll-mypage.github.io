# Before publishing

The website is functional. Complete these items before making it public:

1. Replace the LL avatar with a professional profile photo (`assets/profile.jpg`).
2. Add your real Google Scholar URL.
3. Add your ORCID URL.
4. Add your LinkedIn URL.
5. Add your GitHub profile URL.
6. Review whether you want `Litleserve@gmail.com` public; replace it with a university/professional email if preferred.
7. Add real research figures/screenshots to the project cards.
8. Check publication titles/author order/DOIs one final time.
9. Add new awards, conferences and workshops to `journey.html`.
10. Optional: connect a custom domain after GitHub Pages is live.
